# CS_300

•	What was the problem you were solving in the projects for this course?  
&nbsp;&nbsp;&nbsp;&nbsp;The problem I solved for this course was determining a data structure that could efficiently take in and sort information about college courses for ABC University. I also created a program that parsed data from a csv file and inserted it into a binary search tree. The structure of a binary search tree made ordering the course information simple and allowed users to display information about the courses.  
    
•	How did you approach the problem? Consider why data structures are important to understand.  
&nbsp;&nbsp;&nbsp;&nbsp;I approached this problem by creating pseudocode and calculating runtimes for three data structures, vectors, hash tables, and binary trees. My runtime analyses need further refinement, but they did help me understand how my code would run. It is important to understand different data structures because one data structure may be particularly suited to a certain task over another. Choosing the best data structure for the task means that code, structures, and functionality are easier to implement. When a structure needs to handle a lot of data, it becomes incredibly important that it works well, works consistently, and is streamlined for easy maintenance.  
    
•	How did you overcome any roadblocks you encountered while going through the activities or project?  
&nbsp;&nbsp;&nbsp;&nbsp;The most difficult part of the activities for this project was completing the runtime analysis of all three data structures. For this roadblock, I tried to stay focused on the smaller pieces so that the big picture would not become overwhelming. This is a roadblock that I intend to revisit to continue developing my understanding of Big O notation, runtime analysis, and space complexity. These topics seem to have much more depth than I was able to explore during this course.  
    
•	How has your work on this project expanded your approach to designing software and developing programs?  
&nbsp;&nbsp;&nbsp;&nbsp;Working on this project has expanded my approach do design and development by helping me understand the importance of being intentional in choosing a data structure to solve a problem. The data structure can make or break a program. It is important to invest time in inspecting the data involved, considering what needs to be done with that data, and researching to ensure that the most compatible, efficient data structure is selected to complete the goal. It is a worthwhile investment of time to become familiar with a variety of data structures and the algorithms used to implement them.  
    
•	How has your work on this project evolved the way you write programs that are maintainable, readable, and adaptable?  
&nbsp;&nbsp;&nbsp;&nbsp;This project has helped me practice creating pseudocode that I can use to guide my programming. It has also taught me that, while creating pseudocode helps form a solid idea of what a program will do and how it will work, it is important to be adaptable and recognize when an element of a plan is not working. It has helped me to be able to isolate tasks executed within the program so that, if there is a bug the needs to be fixed or an adjustment that needs to be made, anyone maintaining the code should easily be able to find the code behind that task and make adjustments. I tried to develop my code comments to not only say what a method was for, but also to give an idea of the thought process behind that method and how it interacted with the rest of the program. I think this is important, especially for a binary search tree that utilizes recursive methods and wrappers. Being intentional about data structures, writing compartmentalized methods, and creating comments that will help guide maintenance on the code all  help to make code that is maintainable, readable, and adaptable.
